Experiment Aim

To study and simulate error detection techniques used in the Data Link Layer of Digital communication networks using Vertical Redundancy Check (VRC) and Longitudinal Redundancy Check (LRC).

02

Theory

Concepts behind error detection

1. Error Detection

During data transmission, bits may change because of noise or interference in the communication channel. Error detection techniques add redundant bits to the original data so that the receiver can check whether the received data may contain errors.

2. Vertical Redundancy Check (VRC)

VRC is a one-dimensional parity technique. A parity bit is added to a data unit so that the total number of 1s follows the selected parity rule.

  • Even parity: The total number of 1s, including the parity bit, must be even.
  • Odd parity: The total number of 1s, including the parity bit, must be odd.

The receiver checks the parity of the received bits. A parity mismatch indicates a possible transmission error. VRC may fail to detect errors when an even number of bits change.

3. Longitudinal Redundancy Check (LRC)

LRC arranges data bits into rows and calculates parity for corresponding columns. The calculated column parity bits form an additional parity row.

In this simulation, LRC demonstrates column parity. A mismatch between the calculated and received column parity indicates a possible error. Column parity alone does not identify every error position.

4. Difference Between VRC and LRC

Feature VRC LRC
Method Parity for one data unit Parity across columns of data
Organization One-dimensional Two-dimensional data arrangement
Redundancy One parity bit per data unit One parity bit per column
Limitation May miss even-numbered bit errors Column parity alone has limitations

Procedure

Steps to perform the experiment

Part A: VRC Simulation

  1. Open the VRC simulation tab.
  2. Enter a binary data sequence containing only 0s and 1s.
  3. Select even parity or odd parity.
  4. Generate the parity bit and transmitted frame.
  5. Optionally flip a bit to simulate a transmission error.
  6. Observe the parity check result.

Part B: LRC Simulation

  1. Open the LRC simulation tab.
  2. Enter binary data of equal length in each row.
  3. Generate the column parity bits.
  4. Observe the generated LRC parity row.
  5. Optionally flip a data bit or parity bit.
  6. Observe whether the column parity check detects a mismatch.

Part C: Assessment

  1. Answer the Pre-Test questions.
  2. Perform both simulations.
  3. Answer the Post-Test questions.
  4. Open the Result tab to review the experiment.

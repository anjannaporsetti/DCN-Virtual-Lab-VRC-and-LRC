Theory

Concepts and working of VRC and LRC

1. Error Detection

During data transmission, bits may change due to noise or interference in the communication channel. Error detection techniques add redundant bits to the original data so that the receiver can identify possible transmission errors.

2. Vertical Redundancy Check (VRC)

Vertical Redundancy Check (VRC) is a simple error detection technique in which an additional parity bit is appended to the binary data. The parity bit is calculated using either even parity or odd parity.

  • Even Parity: The total number of 1s, including the parity bit, must be even.
  • Odd Parity: The total number of 1s, including the parity bit, must be odd.

Working of VRC

The sender counts the number of 1s in the data and generates a parity bit. This parity bit is appended to the original data and transmitted. At the receiver, the parity is checked again. A parity mismatch indicates an error.

Example of VRC

Binary Data: 1011001

Number of 1s: 4

Parity Type: Even

Parity Bit: 0

Since the original data contains four 1s, the even parity bit is 0. If an odd number of bits changes during transmission, the receiver detects a parity mismatch. VRC may fail to detect an even number of bit errors.

3. Longitudinal Redundancy Check (LRC)

Longitudinal Redundancy Check (LRC) is an error detection technique in which binary data is arranged into multiple rows. Parity bits are calculated for corresponding columns to form an additional parity row.

In this virtual lab, a two-dimensional parity matrix is used. Both row parity and column parity are calculated using even parity. These checks can detect errors and help locate a single-bit error.

Working of LRC

The sender arranges the data into a matrix and calculates row and column parity bits. The complete matrix is transmitted. At the receiver, parity checks are performed again. A mismatch in one row and one column identifies the position of a single-bit error.

Figure 4: Two-dimensional even parity matrix

The parity bits are generated so that each complete row and column contains an even number of 1s. The bottom-right bit maintains parity for the added parity row and column.

For example, if the data bit at Row 2, Column 2 changes from 1 to 0, the parity checks for Row 2 and Column 2 fail. Their intersection identifies the error position.

Limitation: Some multiple-bit error patterns may not be detected. A unique error position cannot always be determined when multiple bits change.

4. Difference Between VRC and LRC

Feature VRC LRC
Method Parity for one data unit Parity across columns
Organization One-dimensional Multiple data rows
Parity Even or Odd Even in this simulation
Error Location Cannot locate the error 2D parity can locate a single-bit error
Limitation May miss even-bit errors May miss some multiple-bit error patterns

Procedure

Steps to perform the experiment

Part A: VRC Simulation

  1. Open the VRC simulation tab.
  2. Enter a binary data sequence of 1 to 8 bits containing only 0s and 1s.
  3. Select even parity or odd parity.
  4. Generate the parity bit and transmitted frame.
  5. Optionally flip a bit to simulate a transmission error.
  6. Observe the parity check result.

Part B: LRC Simulation

  1. Open the LRC simulation tab.
  2. Select a matrix size from 3×3 to 6×6.
  3. Enter binary data of the selected length in each row.
  4. Generate the column parity bits.
  5. Observe the generated LRC parity matrix.
  6. Optionally flip a data bit to simulate a transmission error.
  7. Observe whether the row and column parity checks detect the error.

Part C: Assessment

  1. Perform both simulations.
  2. Answer the quiz questions.
  3. Open the Result tab to review the experiment.
